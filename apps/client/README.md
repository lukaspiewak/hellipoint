# @heliopolis/client

Aplikacja Vite, która otwiera pusty, renderowany przez Three.js canvas —
dowód rury renderującej dla Fazy 2A, Zadanie 1. Bez planety, geometrii ani
kamery gry (to Zadania 2-4).

## Uruchomienie

Z korzenia repo:

```sh
pnpm dev
```

albo bezpośrednio przez filtr workspace:

```sh
pnpm --filter @heliopolis/client dev
```

Otwiera serwer deweloperski Vite pod `http://localhost:5180/`.
